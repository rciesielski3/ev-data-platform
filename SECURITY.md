# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's "Report a vulnerability" option on the Security tab of this repository. Do not open a public issue.

You can expect an acknowledgement within 7 days. This is a best-effort, solo-maintained project.

## Scope

The application code, cron endpoints and import pipeline in this repository. Upstream data sources (EIPA / UDT, OpenEV Data) and hosting providers are out of scope.
